=== TRIBE SYSTEM DATA FLOW ARCHITECTURE ===

1. USER DATA (Name, Bio, Username, Followers/Following)
   - STORAGE: MongoDB 'User' Collection.
   - IMAGES (Avatar/Banner): Base64 sent to Backend -> Uploaded to Cloudinary ('tribe/avatars' folder) -> URL stored in MongoDB.
   - FETCH: GET /api/users/profile (Current User) or GET /api/users/:id (Others).
   - CACHE: Stored in 'currentUser' and 'allUsers' localStorage keys on Frontend.

2. POST DATA (Text, Image)
   - STORAGE: MongoDB 'Post' Collection.
   - IMAGE: Base64 sent to Backend -> Uploaded to Cloudinary ('tribe/posts' folder) -> URL stored in MongoDB.
   - FLOW: CreatePost.tsx -> handleAddPost (Optimistic) -> api.createPost -> Socket.io emits 'newPost' to all online users.
   - FETCH: GET /api/posts/feed (Following + Me).
   - CACHE: Stored in 'feed_posts' localStorage.

3. STORY DATA (Temporary 24h)
   - STORAGE: MongoDB 'Story' Collection (with TTL index).
   - IMAGE: Same Cloudinary flow as Posts.
   - FLOW: StoryCreator.tsx -> api.createStory -> App.tsx updates myStories state.
   - FETCH: GET /api/stories/feed (Grouped by User).

4. PRIVATE MESSAGING (DMs)
   - STORAGE: MongoDB 'Message' Collection.
   - FLOW: MessageArea.tsx -> api.sendMessage -> Socket.io emits 'newMessage' to specific User Room.
   - REAL-TIME: Socket.io handles typing indicators and message delivery instantly.
   - FETCH: GET /api/messages/:otherUserId.

5. TRIBE CHAT (Group)
   - STORAGE: MongoDB 'Tribe' (Meta) and 'TribeMessage' (Content) Collections.
   - FLOW: TribeDetailPage.tsx -> api.sendTribeMessage -> Socket.io emits 'newTribeMessage' to Room 'tribe-{id}'.
   - FETCH: GET /api/tribes/:id/messages.

6. NOTIFICATIONS
   - STORAGE: MongoDB 'Notification' Collection.
   - FLOW: Action (Like/Follow) -> Backend creates Doc -> Socket.io emits 'newNotification' to Recipient.
   - FETCH: GET /api/notifications.

=== WHERE IT BREAKS (TROUBLESHOOTING) ===
- Blank Feed: Usually a 502/Timeout. Fix: FE Cache + DB Indexes.
- Image Upload Fail: Cloudinary API Key error or Payload too large (>50mb).
- Chat Not Working: Socket.io connection failed (Check SOCKET_URL).
- Message Sent but Disappears: Optimistic UI failed or Backend returned 500.
